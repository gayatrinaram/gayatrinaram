## 🚀 Featured Projects

### 1. RGB Field Image Explorer
[Repository →](https://github.com/gayatrinaram/Soil-Quality-MONITORING) · [Open notebook in Colab →](https://colab.research.google.com/github/gayatrinaram/Soil-Quality-MONITORING/blob/main/Soil_Quality_Monitoring.ipynb)

An exploratory computer-vision project that uses OpenCV and NumPy to calculate and visualise a red-blue colour index from an uploaded field image. Includes a Streamlit interface, reusable image-processing functions and tests.

**Tech:** Python · OpenCV · NumPy · Streamlit

> Technical note: this is not scientific NDVI. True NDVI requires red and near-infrared reflectance bands. The RGB index is an exploratory visual proxy, not a soil or crop-health measurement.

### 2. BMI Category Classification
[Repository →](https://github.com/gayatrinaram/Diabetes-Prediction-using-Python-and-Logistic-Regression) · [Open notebook in Colab →](https://colab.research.google.com/github/gayatrinaram/Diabetes-Prediction-using-Python-and-Logistic-Regression/blob/main/Diabetes_Prediction_using_Python_and_Logistic_Regression_Project.ipynb)

A supervised machine-learning workflow using scikit-learn and Logistic Regression to classify records into BMI categories. Includes preprocessing pipelines, stratified evaluation, a reusable training script and batch prediction.

**Tech:** Python · pandas · scikit-learn · Matplotlib · joblib

> The repository retains its historical name, but the implemented target is BMI category, not diabetes diagnosis. It is an educational project, not a medical tool.
